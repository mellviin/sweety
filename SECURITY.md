# Security

To report a vulnerability in Sweety, please do not open a public issue. Use GitHub's
[private vulnerability reporting](https://github.com/mellviin/sweety/security/advisories/new)
to send the repository maintainers a confidential report. Include reproduction steps,
affected versions, and impact, but do not include real credentials or personal data.

Maintainers should acknowledge reports promptly, coordinate a fix and disclosure with the
reporter, and avoid publishing exploit details before users can update.
